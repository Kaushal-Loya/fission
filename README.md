# Prune.dev

Prune.dev is an AI-powered repository analysis tool that detects unused code, dead APIs, redundant files, and bloated modules. It helps engineering teams reduce codebase size, improve maintainability, and ship faster.

## Core value proposition
"Automatically detect and remove dead code. Reduce your codebase by up to 23%."

## Target audience
* Backend engineers
* Full-stack developers
* Engineering teams working with large repositories
